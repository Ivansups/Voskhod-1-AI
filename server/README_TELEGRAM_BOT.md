# Telegram Bot для AI-ассистента университета

## Описание

Telegram-бот предоставляет удобный интерфейс для общения с AI-ассистентом университета. Бот интегрируется с RAG-системой и автоматически завершает диалог через 3 минуты бездействия.

## Возможности

- 🤖 Общение с AI на основе учебных материалов
- 📚 Показ источников ответов
- ⏰ Автоматическое завершение диалога через 3 минуты бездействия
- 📝 История сообщений
- 🎯 Поддержка команд для управления диалогом

## Архитектура API ключей

Бот использует индивидуальные API ключи с **предварительной привязкой к Telegram ID**:

### Принцип работы:
1. **Администратор генерирует ключ** с указанием Telegram ID студента: `POST /keys?telegram_id=123456789`
2. **Студент активирует ключ** через бота командой `/activate <ключ>`
3. **Система проверяет совпадение**: Ключ может быть активирован ТОЛЬКО указанным Telegram ID
4. **Персональный доступ**: После активации ключ работает только с этим аккаунтом

### Безопасность:
- ✅ **Предварительная привязка**: Ключ генерируется для конкретного Telegram ID
- ✅ **Невозможность дележки**: Чужой ключ невозможно активировать
- ✅ **Проверка на каждом запросе**: API валидирует принадлежность ключа
- ✅ **Учет использования**: Счетчик запросов для каждого пользователя

### Флоу использования:
```
Админ → Генерирует ключи → Выдает студентам
                    ↓
Студент → /activate <ключ> → Активация
                    ↓
         → /dialog → Проверка ключа → Диалог с AI
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Перезапуск бота и проверка активации ключа |
| `/help` | Справка по командам |
| `/activate <ключ>` | Активация API ключа |
| `/dialog` | Начать RAG-диалог (требует активации) |
| `/status` | Показать статус активации ключа |
| `/history` | Показать историю сообщений |
| `/end` | Завершить текущий диалог |

## Запуск

### 1. Установка зависимостей

```bash
poetry install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# API Base URL
API_BASE_URL=http://localhost:8000
```

### 3. Получение токена Telegram бота

1. Напишите [@BotFather](https://t.me/botfather) в Telegram
2. Используйте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### 4. Запуск бота

```bash
cd server/src/application/services/telegram
python main.py
```

## Логика автозакрытия диалога

1. **0:00** - Пользователь начинает диалог (`/chat`)
2. **2:30** - Предупреждение: "Диалог завершится через 30 секунд"
3. **3:00** - Автоматическое завершение с сообщением о причине

При любом сообщении пользователя таймер сбрасывается.

## FSM состояния

- `idle` - Ожидание команд
- `chatting` - Активный диалог
- `timeout_warning` - Предупреждение о завершении
- `closed` - Диалог завершен

## Логирование

Бот ведет логи в:
- Консоль (stdout)
- Файл `telegram_bot.log`

## Безопасность

- Проверка API ключей через заголовок `X-API-Key`
- Валидация входящих данных
- Graceful обработка ошибок
- Ограничение истории сообщений (последние 50)

## Разработка

### Добавление новых команд

1. Добавьте обработчик в `handlers/commands.py`
2. Зарегистрируйте роутер в `main.py`

### Добавление новых состояний

1. Добавьте состояние в `states.py`
2. Создайте соответствующие обработчики

## Troubleshooting

### Бот не отвечает

1. Проверьте токен бота в `.env`
2. Убедитесь что API сервер запущен
3. Проверьте логи на ошибки

### Ошибки API

1. Проверьте `API_BASE_URL` в `.env`
2. Убедитесь что API ключ правильный
3. Проверьте доступность API эндпоинта

### Проблемы с таймером

1. Проверьте логи на сообщения о таймерах
2. Убедитесь что нет исключений в обработчиках
